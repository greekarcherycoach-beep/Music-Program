# Dj Ape1 — εφαρμογή για Windows 10/11 (έκδοση 2)

Παράγονται δύο αρχεία στον φάκελο `dist`:
- **DjApe1-Setup-2.0.0.exe** — εγκατάσταση (Start Menu, συντόμευση, απεγκατάσταση, "Άνοιγμα με…" για αρχεία ήχου). Δεδομένα στο `%AppData%\dj-ape1`.
- **DjApe1-Portable-2.0.0.exe** — χωρίς εγκατάσταση. Βιβλιοθήκη και ρυθμίσεις στον φάκελο `DjApe1-data` δίπλα στο .exe.

## Τι περιλαμβάνει
**Φάκελοι και βιβλιοθήκη**
- Ανάγνωση φακέλων απευθείας από τα Windows: **χωρίς άδειες**, πολύ γρηγορότερη σάρωση, tags και διάρκεια από το σύστημα αρχείων.
- Αυτόματη ανίχνευση νέων αρχείων στους φακέλους που έχεις προσθέσει.
- Η βιβλιοθήκη αποθηκεύεται **σε αρχείο στον δίσκο** (`library\library.json`) με ατομική εγγραφή και **αυτόματα αντίγραφα ασφαλείας** (τα 5 τελευταία, φάκελος `library\backups`). Ένα χαλασμένο αρχείο αντικαθίσταται αυτόματα από το πιο πρόσφατο υγιές αντίγραφο. Επαναφορά: ⚙ Διαχείριση → Δεδομένα → "Επαναφορά…".

**Windows**
- Πλήκτρα πολυμέσων (Play/Pause, Next, Previous, Stop), κουμπιά στο εικονίδιο της γραμμής εργασιών, εικονίδιο στο tray με μενού.
- **Κλείσιμο στο tray** και **Έναρξη με τα Windows** (⚙ Παραμετροποίηση οθόνης → Windows, ή από το μενού του tray).
- Διπλό κλικ σε αρχεία ήχου → παίζουν στον player (Άνοιγμα με → Dj Ape1).

**Μηχανή ήχου mpv** (μενού 🔊 Ήχος → Μηχανή ήχου)
- WASAPI **Exclusive**: η κάρτα ήχου παίρνει το αρχείο στην πραγματική του συχνότητα και bit depth, χωρίς ανάμειξη των Windows.
- **Gapless** αναπαραγωγή, και επιπλέον μορφές (DSD, APE, WV, MKA κ.ά.).
- Δεν υποστηρίζεται ASIO (η mpv δεν το έχει). Για τις περισσότερες κάρτες/DAC το WASAPI Exclusive δίνει την ίδια bit-perfect έξοδο.
- Όσο παίζει με Exclusive, άλλες εφαρμογές δεν έχουν ήχο από αυτή τη συσκευή.

## Χτίσιμο
### Τρόπος 1 — GitHub (χωρίς να εγκαταστήσεις τίποτα)
1. Φτιάξε ένα (ιδιωτικό) repository στο GitHub και ανέβασε **όλο το περιεχόμενο** αυτού του φακέλου, μαζί με τον κρυφό φάκελο `.github`. Με το GitHub Desktop ή με `git` γίνεται εύκολα· στο web μπορείς να σύρεις τον φάκελο μέσα στη σελίδα "Add file → Upload files" (πρόσεξε να περάσει και ο `.github`).
2. Καρτέλα **Actions → Build Windows → Run workflow**. Σε ~10 λεπτά κατεβάζεις τα δύο .exe από τα **Artifacts**.
3. Για δημοσίευση ως Release: δημιούργησε tag, π.χ. `v2.0.0` — τα .exe επισυνάπτονται αυτόματα.
Το workflow κατεβάζει μόνο του την mpv. Αν αποτύχει, το build συνεχίζει και η εφαρμογή δουλεύει με τη μηχανή Chromium.

### Τρόπος 2 — στον υπολογιστή σου (Node.js LTS)
Διπλό κλικ στο `build.bat` (ή `npm install` και `npm run dist`). Η mpv κατεβαίνει αυτόματα. `npm start` τρέχει την εφαρμογή χωρίς build, `npm test` τα αυτόματα τεστ.
Χειροκίνητη mpv: βάλε το `mpv.exe` στον φάκελο `vendor\mpv` (https://mpv.io/installation/).

## Αντιμετώπιση προβλημάτων
- **"Cannot create symbolic link … privilege" στο build:** τα Windows μπλοκάρουν symlinks. Το `build.bat` δοκιμάζει αυτόματα build χωρίς επεξεργασία εικονιδίου. Για το δικό σου εικονίδιο: Ρυθμίσεις → Για προγραμματιστές → Developer Mode ON, διαγραφή του `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign` και νέο build.
- Ακόμα κι αν αποτύχει το packaging, ο φάκελος `dist\win-unpacked` περιέχει λειτουργικό πρόγραμμα (`Dj Ape1.exe`).
- Η mpv είναι GPL/LGPL λογισμικό· το .exe της περιλαμβάνεται όπως διανέμεται από το έργο mpv-winbuild. Για προσωπική χρήση δεν χρειάζεται κάτι· αν διανείμεις την εφαρμογή σε άλλους, κράτα την αναφορά στο mpv.
- Το μήνυμα npm `install-scripts … electron` είναι προειδοποίηση. Αν το `npm start` πει ότι λείπει το Electron: `node node_modules\electron\install.js`.
